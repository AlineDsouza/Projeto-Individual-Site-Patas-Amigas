# 🐾 Patas Amigas

Website fictício de uma associação de proteção animal do Porto, desenvolvido no âmbito do Curso de Software Developer.

## Sobre o projeto

O objetivo é apresentar animais disponíveis para adoção e facilitar o contacto com pessoas interessadas em oferecer-lhes um lar.
